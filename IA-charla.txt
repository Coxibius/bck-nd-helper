💡 PROPUESTA: Implementar un comando `bck-nd docs .` o un flag `--html`.
¿Cómo funcionaría técnicamente?
1. Se crea un `html_renderer.py` que contiene un template HTML base (con el script de MermaidJS embebido y un poco de CSS para que se vea premium).
2. Cuando el usuario lanza el comando, `bck-nd` ejecuta silenciosamente todos los AST parsers en cadena (ER Parser, Route Parser, Infra Scanner, etc.).
3. Los strings resultantes (que ya son gráficas Mermaid válidas) se inyectan en las etiquetas `<div class="mermaid">` del template.
4. El resultado final se escupe como `diagramas_bck_nd.html` directo en la raíz.

Casos de uso letales para el Enterprise Pitch:
