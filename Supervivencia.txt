La respuesta corta a tu pregunta es: NO. No tienes que activar el venv cada vez que uses el agente.

¿Por qué? Porque en el archivo de configuración JSON hicimos trampa de la buena: le pusimos la ruta absoluta ("C:/bck-nd-hlpr/venv/Scripts/python.exe"). Con eso, la IA ya sabe exactamente a qué burbuja entrar automáticamente sin que tú tengas que abrir la terminal.

Solo tienes que activar el venv cuando quieras usar la herramienta tú mismo a mano en la terminal.

MANUAL DE SUPERVIVENCIA: BACKEND HELPER + IA (MCP)
1. USO CON LA INTELIGENCIA ARTIFICIAL (Antigravity / Cursor)

¡No tienes que hacer nada en la terminal!
Como el archivo JSON ya apunta al venv, simplemente abre tu editor, ve al chat de la IA y dile:

    "Usa la herramienta MCP 'backend-helper' para analizar este proyecto y extraer el diagrama UML."
    (La IA se encarga de encender la herramienta en segundo plano).

2. USO MANUAL EN LA TERMINAL (Para generar el HTML tú mismo)

Si quieres sacar la página web oscura hermosa sin usar a la IA, SÍ tienes que activar la burbuja (venv) para evitar el error de Python 3.13.

Paso 1: Abre tu terminal (PowerShell).
Paso 2: Navega a la carpeta de tu herramienta:
cd C:\bck-nd-hlpr
Paso 3: Activa el entorno virtual (la burbuja limpia):
.\venv\Scripts\activate
(Sabrás que funcionó porque aparecerá un texto verde que dice (venv) a la izquierda).
Paso 4: Ahora ve a la carpeta del proyecto que quieras analizar y corre tu programa:
cd C:\ruta\a\tu\proyecto\cualquiera
bck-nd docs . -o mi-documentacion
3. ¿QUÉ PASA SI FORMATEO MI PC O CAMBIO DE COMPUTADORA?

Si algún día la herramienta se rompe o cambias de compu, estos son los 3 comandos mágicos para reinstalar el entorno virtual desde cero:

    Ve a la carpeta de la herramienta:
    cd C:\bck-nd-hlpr

    Borra la carpeta venv vieja (si existe) y crea una nueva:
    python -m venv venv

    Actívala:
    .\venv\Scripts\activate

    Instala tu código dentro de la burbuja:
    pip install . mcp
